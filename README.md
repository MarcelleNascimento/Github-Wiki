# 🔎 GitHub Wiki

Aplicação desenvolvida em React que permite buscar repositórios do GitHub e visualizar informações detalhadas sobre os projetos e seus respectivos usuários.

O objetivo do projeto é praticar conceitos fundamentais do desenvolvimento frontend, como consumo de APIs, gerenciamento de estados, criação de componentes reutilizáveis e organização de uma aplicação React.

## 🚀 Demonstração

Acesse a aplicação:

🔗 https://MarcelleNascimento.github.io/Github-Wiki

## 📌 Funcionalidades

* 🔍 Buscar repositórios através da API do GitHub
* 👤 Exibir informações do usuário responsável pelo repositório
* 📄 Mostrar detalhes do projeto:

  * Nome do repositório
  * Descrição
  * Link para acessar o GitHub
  * Perfil do proprietário
* ❌ Remover repositórios adicionados
* ⚠️ Validação de campos vazios
* ⚠️ Tratamento de erros durante as requisições
* 🚫 Impedir adição de repositórios duplicados

## 🛠️ Tecnologias utilizadas

* React.js
* JavaScript (ES6+)
* Axios
* Styled Components
* GitHub API
* HTML5
* CSS3
